# CSS Positioning Layout

A responsive landing page built with HTML and CSS as a practice project for gradients, positioning, and visual layering.

## Live demo

[Open the website](https://ahmedfceo.github.io/css-positioning-layout/positioning.html)

## Features

- Multi-color linear-gradient hero section
- Float-based card layout with status badges
- Relative and absolute positioning with z-index layering
- Hover transitions and a small keyframe animation
- Responsive layout for narrow screens

## Files

- `positioning.html` — page structure and content
- `style.css` — styling, layout, animations, and responsive rules

## Run locally

Open `positioning.html` in a browser. No build tools or external dependencies are required.

## Built with

HTML5 · CSS3
